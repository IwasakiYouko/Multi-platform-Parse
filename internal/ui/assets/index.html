首次部署或无法登录？

初始用户名为 admin，随机密码保存在服务数据目录的 initial-admin.txt 中。请在部署主机本地读取；首次登录必须修改密码，也可以修改用户名。

Cap 未就绪时禁止登录。请在部署主机启动自托管 Cap 及其 Redis，将 Cap 的 ADMIN_KEY 安全写入权限为 0600 的本地文件，并为本服务设置 CAP_ADMIN_KEY_FILE 指向该文件。服务会使用官方管理 API 初始化站点；无公开免验证初始化入口。

Cap 需配置有效的 REDIS_URL。默认 Cap 地址为 http://127.0.0.1:3000；服务地址必须可从解析服务进程访问。验证组件与 WebAssembly 资源已内置于解析服务，无需启用 Cap 资源服务器，也不依赖 CDN。部署完成后重新连接验证服务。

不要将 Cap 管理密钥、站点服务端密钥或管理员密码发给他人。若已有站点配置，可由部署管理员在本地恢复配置后重启服务。
